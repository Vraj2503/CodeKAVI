Mockup C: File × File Adjacency Heatmap

This is a DEPARTURE from ArchitectureGraph. React Flow renders node-link graphs; this is a heatmap + drill-down panel. It would need d3 or raw canvas/SVG, similar to the existing treemap and heatmap components in the codebase. The trade-off: it handles density better than any node-link layout at the cost of not showing the graph shape (paths, centrality). Consider it a complementary view, not a replacement.

Which Problems It Prioritizes:

  • Problem 1 (Layout): Eliminates it entirely. A 38×38 matrix is dense but has no layout problem — every file gets one row and one column, period. No overlapping, no edge crossings.
  • Problem 3 (Truncation): The matrix can show ALL 657 symbols' relationships (the hidden 488 too) because cell values are just counts. The drill-down shows the top-150 detail. Makes the full/truncated distinction natural.
  • Problem 2 (Resolution): Natural place for it — the diagonal band of the matrix. Self-calls within a file plus the unresolved calls create a natural "darkness along the diagonal" that the legend explains.
